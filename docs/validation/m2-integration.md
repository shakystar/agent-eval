| 점검 항목 | 통합 동작 |
| --- | --- |
| 과제 승인 철회 | 승인 후 반려하면 원래 검토를 보존하고 해당 과제의 확정 성공률을 보류합니다. |
| 사람 기준의 출처 | 합성·출처 미확인 라벨은 사람 기준 분모에서 제외합니다. 기존 저장소는 그대로 읽고, 실제 검토를 명시적으로 확인한 등록만 사람 기준으로 사용합니다. |
| 근거 인용 | 새 이진 판정은 입력 또는 산출물의 원문 인용을 요구합니다. 없는 구절을 인용하면 채점 오류로 기록합니다. |
| 수행 성능 | 완료된 실행에서 필수 판정을 사람이 확정하고 과제를 승인해야 확정 성공률에 반영합니다. 표본이 없을 때는 미측정 사유를 표시합니다. |
| 호출 복구 | 실모델 호출은 `semantic-grade`에서 예산과 평가 ID를 확인한 뒤 항목별 호출 의도와 결과를 저장합니다. 기존 형식의 중단된 작업은 원래 계약으로 재개합니다. |
