2026-11-20에 M3 커밋 `dcac71f`의 공통 CLI로 기존 결제 점검 공지와 두 번째 후보인 **재고 대사·보충 결정**을 같은 저장소에서 실행하고 평가했다. 공개 입력 두 개를 조합해 숫자와 업무 결정을 내리는 과제이므로, 공지문과 다른 입출력 계약을 기존 엔진이 처리하는지 확인할 수 있다.

검증 전에 각 저장소의 `main`에 반영한 M3 변경은 `agent-eval@dcac71f`, `role-orchestrator@7226171`, `role-runtime@9ca52f2`와 계정 라우팅 임시 조치를 문서화한 `codex-adapter@e063dc4`다.

## 실행 결과

기존 Linux 이미지에서 네트워크와 이미지 다운로드를 끄고 실행했다. 이미지의 `agent_eval/` 소스가 해당 커밋과 일치했다. 기존 M1 20개, M2 8개, M3 15개 회귀 검사가 모두 통과했다.

| 사례 | 건수 | 규칙 평가 결과 |
| --- | ---: | --- |
| 기존 공지문을 fixture로 실행 | 1 | 충족. M3의 산출물 존재 규칙 사용 |
| 재고 정답을 fixture로 실행, 키 순서를 바꾼 정답 가져오기 | 2 | 모두 충족 |
| 보충 수량 오류, 가용 재고에 불리언 제출, 보충 여부 오류 | 3 | 각각 해당 기준 하나만 미충족 |
| 잘린 JSON, 완료 시 수집한 빈 문자열 | 2 | 각각 필수 기준 세 개 모두 미충족 |
| 출력을 수집하지 못했고 실행 완료 여부도 불확실한 기록 | 1 | 판정 불가. 계획 분모에 포함 |

재고 8건은 충족 2건, 미충족 5건, 판정 불가 1건으로 예상 판정과 모두 일치했다. [실행에서 생성한 결과 요약](m4/preflight-summary.json)

재고 과제는 기초 8개에 입고 3개를 더하고 출고 8개와 파손 2개를 차감한다. 가용 재고 1개가 발주점 3개 미만이므로 목표 7개까지 보충할 수량은 6개다. 세 항목을 기존 Inspect 어댑터의 `json_equals`로 평가했다. 공개 입력에는 원장과 보충 정책을 제공했다.

두 과제 모두 정상 CLI로 등록·실행·평가·보고했다. 완료된 실행을 bridge 없이 다시 조회했을 때 영수증이 같았다. 저장 사례 7건은 재가져오기 시 중복으로 인식했다. 같은 증거로 자식 평가를 생성해 최초 판정과 비교한 결과 두 보고서의 조건별 결과가 같았다. 최초 평가와 재평가 각각 공지 1항목과 재고 24항목을 처리했고 채점기 오류는 0건이었다. 실행 입력과 실제 전송 요청에서 비공개 루브릭 원문을 검사했고 공개 JSON 및 Markdown 보고서에도 해당 원문이 없었다.

## M4 착수 범위

- 재고 원장·정책·평가 기준을 버전이 있는 정식 과제 묶음으로 구성한다. 보충이 필요한 이번 사례 외에 재고가 발주점과 정확히 같은 경우와 목표 이상인 경우를 별도 검증 사례에 둔다.
- 두 묶음의 CLI 회귀를 정식 검증 경로에 연결하고 첫 버전의 C-01~07 완료 증거를 대조한다. [통합 기준](../research/inspect-harbor.md)
- 이번 과제의 타당성 상태는 `unreviewed`다. 이번 수치는 합성 사례의 예상 판정과 일치한 건수다. 실제 모델 성능이나 사람 기준과의 일치도를 보고하려면 두 번째 과제에 대한 독립 기준 사례가 필요하다.

## 재현

저장소 루트에서 기존 `agent-eval-m3:dev` 이미지로 실행한다. 새 디렉터리에 입력, 영수증, 두 과제의 최초·재평가 보고서와 `summary.json`이 생성된다. [사전 검증 스크립트](../../experiments/m4/preflight.py)

```sh
mkdir -p artifacts
run_dir=$(mktemp -d "$PWD/artifacts/m4-preflight.XXXXXX")
docker run --rm --pull=never --network none \
  --mount "type=bind,source=$run_dir,target=/work" \
  --mount "type=bind,source=$PWD/experiments/m4/preflight.py,target=/tmp/preflight.py,readonly" \
  --entrypoint python agent-eval-m3:dev /tmp/preflight.py /work
```
