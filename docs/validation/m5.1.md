# M5.1 고정 협업 사례 검증

2026-11-22에 결제 점검 공지문 6건을 공통 CLI로 검사했습니다. 최종 공지문에는 중단 시간, 탐색 가능 여부, 재시도 안내가 필요합니다. 같은 초안에 앞의 두 항목만 넣고 검토 결정과 수정 여부를 바꿨습니다. 고정 응답을 사용하는 실행 5건과 저장 산출물 가져오기 1건을 사용했으며 모델 호출은 0건입니다. [검증 코드](../../tests/validate_m51.py) · [검증 결과와 증거 해시](m5.1/validation.json)

| 사례 | 최종 산출물 판정 | 최초 인계에서 확인한 항목 | 장애 주입 및 복구 |

## 판정 계약

- **최종 산출물**은 완료된 실행의 마지막 작성본에 과제의 필수 채점 기준을 적용합니다. 첫 사례에서 검토자의 수락은 성공 조건에 들어가지 않습니다. 중단 전에 남은 초안에는 `final_artifact_not_reached`를 기록합니다. 이 검증의 판정은 모두 규칙 평가 초안입니다.
- **필수 정보 인계율**은 과제 버전에 선택 필드 `required_handoff`로 지정합니다. 각 항목은 고유한 `id`와 대소문자를 구분하는 고정 문자열 `contains`를 갖습니다. 최초 작성자→검토자 인계에서 전송 요청과 성공 영수증의 입력이 같고, 전달 문서 해시가 작성자 출력과 같아야 내용 일치를 검사합니다. 과제 설명, 추가 자료, 최종 수정본에만 있는 문자열은 최초 인계 실적으로 세지 않습니다. 이 방식은 고정 문구 전달을 검사하며 자유로운 바꿔 쓰기의 의미 평가는 후속 범위입니다.
- **복구 성공률**은 계획된 `read_handoff` 장애의 적용이 확인된 실행만 분모에 넣습니다. 저장된 복구 결과가 `read_succeeded`인 실행이 분자입니다. 적용 미확인과 미적용은 사유별로 제외합니다. 장애 자체의 복구와 이후 과제 완료는 별도 판정입니다.
- **누락 표시**는 두 보고서에서 같은 규칙을 씁니다. 계획된 인계 항목은 증거가 누락되어도 분모에 남습니다. 모든 항목의 증거가 없으면 JSON 값은 `null`이고 Markdown은 원시 분수와 `missing_handoff_evidence`를 표시합니다. 분모가 0이면 `zero_denominator`입니다. `excluded_slots`는 분모에서 빠진 실행 수이며, `reason_counts`는 미전달·미관찰·복구 실패를 포함한 사유별 건수입니다.

## 재현

기존 [M3 환경](../m3-execution.md)에서 저장소 루트의 Linux/WSL 셸로 실행합니다. 아래 이미지 ID는 검증 당시 사용한 로컬 이미지입니다. 저장소의 현재 소스를 읽기 전용으로 연결합니다. 출력 경로에는 컨테이너 사용자에게 쓰기 권한이 있어야 합니다.

```sh
mkdir -p artifacts
out=$(mktemp -d "$PWD/artifacts/m51.XXXXXX")
docker run --rm --pull never --network none \
  --mount "type=bind,source=$PWD,target=/repo,readonly" \
  --mount "type=bind,source=$out,target=/out" \
  --workdir /repo -e PYTHONDONTWRITEBYTECODE=1 -e PYTHONPATH=/repo:/opt/src/role-orchestrator \
  --entrypoint /opt/inspect-env/bin/python \
  sha256:df130e0925f664fd2224d757b4d60171d451eb1791bf7586866bc2b21d923619 \
  /repo/tests/validate_m51.py /out
```

두 실험에서 각각 최초 평가와 자식 재평가를 수행해 JSON·Markdown 4쌍의 분자·분모·제외 사유를 확인했습니다. 재평가 전후의 원본 증거 해시, 최초 판정, 실행 의도 수가 일치했습니다. 저장소 복사본에서 네 평가 ID의 보고서를 다시 생성해 JSON과 Markdown이 각각 바이트 단위로 일치하는 것도 확인했습니다. 읽기 실패와 영수증 미관찰은 검증 코드에서 통제하며 적용 여부 `uncertain`의 분모 제외는 별도 고정 관측으로 검사했습니다.
