# 목표에서 시작한 Python 개발 인수

입력은 단독 UTF-16 서로게이트를 거부하고 정상 유니코드를 보존하라는 목표, 사례 ID, 기준 커밋, 대상 Python 파일 경로 한 개였습니다. 시나리오·인수 조건·회귀 검사·패치를 명부의 역할들이 작성했습니다. 독립 검사자는 역할 배정 전에 별도 반례를 고정해 기준 실패를 확인했습니다. 모델 컨테이너에서 이 반례와 실행 로그를 읽을 수 있게 한 시점은 패치 검토가 끝난 뒤입니다. [최초 입력과 지문](initial-review.json) · [독립 반례](strict_json_unicode_check.py)

| 실모델 단계 | 결과 |
|---|---|
| 시나리오 acl-001 → 식별자 acl-002 → 중단 창 acl-003 → 벡터 acl-004 | 네 역할이 각자 산출물을 제출했습니다. |
| 벡터 검토 acl-005 → 벡터 보완 acl-004 → 재검토 acl-005 | 문자열 중간의 고립 서로게이트 사례가 빠져 보완 요청이 발생했습니다. 검토자가 보완한 벡터를 수락했습니다. |
| 회귀 acl-008 → 구현 acl-007 | 테스트 파일 추가와 파서 수정이 서로 다른 세션에서 독립된 패치로 제출됐습니다. |
| 패치 검토 acl-005 → 같은 역할 재검토 | 첫 응답의 판정값 `unverified`가 계약에서 허용되지 않아 실패했습니다. 재검토자는 같은 패치 해시를 수락했습니다. |
| 실행 증거 검토 acl-009 → 같은 역할 재검토 | 첫 검토는 기준·후보 차이를 확인하고 후보 빌드 식별자 누락을 지적했습니다. 과제 커밋의 전체 트리를 두 패치와 대조하고 그 커밋에서 검사를 다시 실행한 뒤 최종 수락했습니다. |

고정 명부의 고유 구성원 8명이 총 13회 배정됐습니다. 원본 Go 시도에서 실행·입력·역할·영수증을 다시 결속했습니다. Go 변경 담당 acl-006은 배정되지 않았습니다. 모델명과 추론 강도는 요청 당시의 설정입니다. [검증한 13개 시도와 수락 판정](accepted.json) · [최초 증거 보류](initial-evidence-read.json)

## 격리 검증

| 실행 | 기준 | 후보 |
|---|---|---|
| 독립 검사 | 기준 소스에서 단독 서로게이트를 허용해 종료 1 | 구현 패치만 적용한 트리에서 종료 0 |
| acl-008 회귀 | 회귀 패치만 적용한 트리에서 테스트 메서드 2개를 수집하고 하위 사례 24개 실패, 종료 1 | 두 패치를 적용한 트리에서 같은 메서드 2개 통과, 종료 0 |

각 실행은 읽기 전용 소스와 네트워크 없는 Docker에서 수행했습니다. 구현 파일 한 개와 테스트 파일 한 개가 바뀝니다. 기준 `2ac1621`에 두 원본 diff를 적용한 전체 트리 SHA는 `6c23f4907f0cc1c2f0d814fc22e6b85e36e0b65f`입니다. 해당 트리를 가진 과제 커밋 `401080b`을 새로 체크아웃해 독립·역할 검사 모두 재실행했습니다. 기록한 이미지 지문은 소스가 읽기 전용으로 마운트된 실행 환경을 식별합니다. [원본 패치](author.patch) · [원본 회귀 패치](regression.patch) · [최초 실행](execution.json) · [과제 커밋 실행](execution-r1.json)

같은 후보 이미지가 있는 Linux에서 아래 명령을 실행하면 기준과 후보 네 트리를 새 디렉터리에 생성해 두 검사 결과를 대조합니다. unittest 실행 시간은 재실행 시 달라질 수 있습니다.

```sh
sh reproduce.sh /path/to/role-orchestrator /new/output-directory
```

실행 도중 세 차례의 보완에 맞춰 컨트롤러를 갱신했습니다. 최종 커밋에서의 오프라인 재생은 동일한 증거와 상태에 대한 판정 일치 여부를 검사합니다. [재현 스크립트](reproduce.sh) · [상태 재생](offline-replay.json)

## 검증 범위

Python 파서 결함 한 건에서 고정된 명부 경로의 개발과 독립 인수를 검증했습니다. 식별자·중단 창 역할의 산출물에는 이 과제에서 직접 변경할 필요가 없는 실행 ID와 재제출 판단도 들어갔습니다. 이들 역할을 생략한 대조군을 실행하지 않아 8명이 이 과제의 최적 인원인지는 미측정입니다. 증거 실행과 코드 통합은 별도 실행자가 수행했습니다.
