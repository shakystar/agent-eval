# v0.3.1 독립 연구 리뷰의 과보류 검증

**측정 마일스톤 독립 인수 완료 · 현행 acl-025 유지.** 후보의 의미 판정 수치는 사전 기준을 넘었지만, 최초 현행 비교의 유효 리뷰 1건과 최초 현행 선제 신호의 종합·기획 결정 영수증이 없어 독립 인수팀이 후보 적용을 보류했다. 연구팀 3인과 모델 배정을 유지했다. 후보는 독립 반증 담당자의 지시문 한 줄을 개정해, 원문의 관측과 확대 해석을 각각 판정하고 누락 자료를 그 자료가 필요한 주장에만 연결한다. [대상 후보](https://github.com/shakystar/agent-collaboration-lab/commit/bf4650c7a0c3d57f370f0ce73aca0ae5bacd2962) · [독립 판정](verdict.json) · [단계별 이슈](https://github.com/shakystar/agent-eval/milestone/4)

## 비교 방법

후보 작성 전에 합성 사례·채점표·채택 기준을 동결했다. 기획팀 인계 후 개발팀 작성자에게 원 지시문과 교정 사례만 제공했다. 같은 사례의 양쪽 배정 입력과 초안 해시는 같으며 실제 턴에서 Astra high를 확인했다. 명부 개정에 따라 달라진 역할 지시문은 독립 검토자 acl-025 한 줄이다. [동결 기록](https://github.com/shakystar/agent-eval/issues/27#issuecomment-7147342246) · [사전 기준](protocol.json)

미공개 의뢰 2개와 선제 신호 2개에 각각 자유 서술 주장 2개를 제시하고 두 번씩 실행했다. 관측과 확대 해석의 판정에 리뷰가 직접 미치는 영향을 분리하려고 미공개 초안의 저자 선행 제약과 관측 담당자의 필수 누락 표시는 비웠다. 합성 초안은 평가자가 고정했고 검토 문구는 실제 모델이 작성했다. 제품의 review 검증기와 synthesize 판정 함수로 주장별 상태를 읽었다. 반대·판단 유보 의견은 그대로 유지하는 고정 매핑을 사용했다. 과거 실모델 초안 2개는 원래 선행 제약을 보존해 별도 재생했다. 상위 팀의 종단간 실행은 별개다. [동일 배정 입력](replay) · [사례별 결과](measurements.json)

H4 첫 실행에서 현행은 서명 누락 두 건이라는 기록 자체에도 중복 제거·재현 자료를 요청했다. 후보는 두 건이라는 기록을 지지하고 ‘전체의 절반’이라는 주장에만 분모를 요청했다. 공통으로 유효한 7쌍에서도 과보류는 3건에서 0건으로 줄었다. 사례별 악화는 없었다. 실제 회신·재개발 횟수는 측정하지 않았다. 선시작 실패를 포함한 배정 누적 시간은 207.98초와 329.24초이며, 후보에는 모델 시작 전 라우팅 재시도 4회가 포함된다. 시간·비용 개선을 주장하기에는 표본이 작다. 사례 수는 고유 4개다. 과거 초안 두 건 모두 후보에서 관찰 두 개를 허용하고 확대 해석을 보류했다.

사용자 의뢰와 선제 신호에는 합성 원문을 사용했다. 실제 모델이 관측·초안·독립 검토·종합·기획 결정을 수행한다. 기획 결정까지 완료한 흐름은 네이티브 영수증, 단계마다 Go 실행 한 번, 상태 재조회를 확인했다. 현행 신호의 첫 리뷰에서는 검토자가 자신의 ID를 확인할 수 없다며 conflict=true를 반환했다. 네이티브 영수증의 검토자 acl-025는 초안 작성자에 포함되지 않았다. 파이프라인은 안전하게 보류했으며 원래 실패를 보존했다. 고정된 오케스트레이터 전체 회귀는 143회 통과했다. [팀 배정·영수증·초안 해시](pipeline.json) · [회귀 로그](regression.txt)

## 독립 리뷰 보완

최초 독립 리뷰가 현행 H2 첫 실행의 초안 해시 불일치와 선제 신호의 이해충돌 보류에 대한 비교 자료를 요구했다. 같은 조건의 H2와 선제 신호를 양쪽 계약에 새로 배정했다. H2의 직접 관찰은 후보만 통과시켰고 비율 주장은 양쪽 모두 보류했다. 추가 신호는 양쪽 모두 6단계를 완료했다. 독립팀은 추가 실행이 최초 실패를 대체할 수 없다고 판정했다. 다음 후보 검토에 앞서 재측정 절차와 동일 작업 중복 호출을 검출할 반례를 사전 고정하도록 요청했다. 이 결과는 위 사전 점수와 별도다. [추가 배정과 최초 판정](supplement.json)

## 재현

병합 기준 오케스트레이터 3c7af3f와 개발 기준선 브리지를 사용한다. 실험용 상태 디렉터리를 새로 만들고 아래 환경 변수에 해당 경로를 지정한다. LAB은 후보와 기준선 두 커밋을 가진 명부 저장소, INPUT은 이 문서 옆 replay/H1.json 등의 파일이다. REVISION은 기준선 112d4629d4261b4403ff33fbde43e36431c435f4 또는 [후보 커밋](https://github.com/shakystar/agent-collaboration-lab/commit/bf4650c7a0c3d57f370f0ce73aca0ae5bacd2962)이다. 실행 모델 특성상 같은 입력의 새 배정에서도 결과가 달라질 수 있다.

```sh
python -m role_orchestrator.assignment --backend codex --profile planning-team-v1 \
  --lab "$LAB" --revision "$REVISION" --runtime "$BRIDGE" --state "$STATE" \
  --task research-evidence-route--3 --member acl-025 < "$INPUT"
```
