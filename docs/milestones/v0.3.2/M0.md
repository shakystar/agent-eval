## 채점과 실험 규모

- 최초 평가 분모는 사전에 예정한 배정 전체다. 최초 상태는 유효 완료, 규약에 맞는 안전 보류, 기술 실패, 미완료 중 하나다. 마감 시점까지 실행 여부를 모르면 미완료로 분류하고 미상 표지를 보존한다. 검토자 신원 입증 실패는 기술 실패다.
- 사전에 정한 안전 조건이 실제 관측 근거로 확인되면 안전 보류의 적절성을 별도로 채점한다. 보류에 의미 판정이 없으면 의미 점수 분모에서 제외하고 제외 건수와 최초 분모를 함께 공개한다. 복구율은 최초 기술 실패 전체 중 마감까지 동일 배정에서 유효 결과가 확인된 비율이다.
- 인수팀이 숨김 사례·정답·채점표를 보관한다. 개발팀은 합성 예제와 공개 계약을 사용한다. 비교 전 모델·추론 수준·입력·반복·순서·마감·판정 문턱을 기록하고 채점 완료 뒤 비교군을 공개한다.
- 먼저 기존 기록과 테스트 대역을 사용한다. 작은 실험은 동일한 짧은 과제 두 건과 기록 재전달로 구별 여부를 확인한다. 설명되지 않은 차이는 질문이 명시된 소수 진단으로 확인한다. 실제 모델 실험은 후속 단계다.
- v0.3.1 최초 평가 8건씩은 각각 61,225·61,187토큰, 직전 사전 검증 1턴은 13,074토큰이었다. 입력·출력·캐시·재시도·역할별 합계를 기록한다. 20,000토큰 일률 중단선은 두지 않는다. 확대 전 사례별 예상 호출 수·실측 단가·추가 판정 목적을 제시한다. 기존 64개 최초 배정과 132회 상한은 미승인 비교안이다.
- 관측이 불완전하면 판정불가로 현행 계약을 유지한다. 소규모 집계 시험의 통과는 역할 품질 우위의 증거로 쓰지 않는다.

개발 착수 전 각 담당은 실제 관측 위치와 한계, 운영 비용을 채우고 독립 인수팀은 공백별 해소 근거를 재검토한다.
