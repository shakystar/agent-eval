# M1 착수 전 재심 자료

[직전 판정](m1-prestart.json)에서 요구한 두 경로를 과거 합성 실행 기록으로 재구성했다. 재검토 대상은 설계와 관측 가능 범위다.

| 사례 | 확인된 배정 | 최종 결정 | 관측된 총 토큰 |
|---|---:|---|---:|
| SYN-REQ-01 사용자 의뢰 | 5 | hold | 60,667 |
| SYN-SIG-01 선제 신호 | 6 | select_followup | 68,068 |

각 행에서 사례·배정·시도·역할 개정, 앞 단계 영수증 목록, 실제 영수증 원문과 입력·산출물의 SHA-256을 대조했다. 결과의 세션 ID로 어댑터 매핑과 세션 메타를 찾고, 같은 턴 ID의 완료 이벤트와 같은 스레드·턴의 마지막 누적 사용량을 연결했다. 캐시 입력은 입력에 포함된다. 최종 단계에서는 배정에 전달된 패킷 해시와 결정의 패킷 해시, 저장된 결정 본문까지 일치했다. 턴 내부의 제공자 호출·재시도 횟수는 미확인이다. 이 수치는 과거 배정의 비용이며 이번 재심 실행량과 분리한다.

## 제안하는 책임과 인계

- 어댑터는 완료된 턴과 사용량의 출처를 기록한다. 사용량 이벤트 유실은 미상으로 기록한다. 제공자 내부 호출 횟수는 별도 관측 근거가 있을 때만 수치로 보고한다.
- 런타임은 기존 영수증 바이트를 보존하고, 그 해시에 배정·시도·역할·초안·턴·사용량 출처·결과를 연결하는 버전 있는 증빙을 추가한다. 같은 증빙 재전달은 중복 집계하지 않는다. 서로 다른 두 턴은 산출물 해시가 같아도 별도로 기록한다.
- 오케스트레이터는 배정 원장과 최종 결정의 참조를 검증한다. 다른 배정이나 구개정 연결은 실패, 근거 유실은 미확인으로 보류한다. 복구 시 미상인 시도를 자동 재호출하지 않는다.
- 보안 담당에게 환경별 비대칭 서명과 별도 검증 권한을 제안한다. 키 식별자·알고리즘·버전·발급 시점과 서명 대상 바이트 규칙을 고정한다. 회전 후 과거 검증키를 유지하고 유출·폐기 시 영향 기간을 표시한다. 실제 키 서비스와 운영 권한 결정은 열려 있다.
- 운영 담당은 원문과 최소 감사 기록의 보존 기간·권한·삭제 방식을 각각 정한다. 저장 비용은 일 배정 수 × 평균 증빙 크기 × 보존 일수 × 저장 단가로 추정하고, 서명·관측 요금과 개발·운영 공수를 별도 기록한다. 운영량·기간·단가가 없어 금액은 미산정이다.

후속 시험은 고정 기록 재전달과 반환 유실 반례부터 시작한다. 같은 영수증 두 번은 실행 1회, 같은 결과를 낸 두 턴은 2회, 턴 증거가 없으면 미확인이다. 이 기준의 새 구현 통과 여부와 운영 키 검증은 미측정이다.

## 독립 재심과 다음 결정

신유진이 과거 정상 경로를 검토했고, 이서진은 정식 착수를 보류했다. 최종 승인자에게 배정되기 전 종료된 판정이다. 현재 진행 가능 범위는 증빙 스키마·검증 기준 구체화와 합성 시험 설계다.

| 합성 사례 | 입력 | 기대 판정 |
|---|---|---|
| 동일 영수증 재전달 | 같은 배정·시도·턴·영수증 두 번 | 실행 1회, 사용량 한 번 |
| 같은 결과의 별도 실행 | 같은 산출물 해시, 서로 다른 두 턴의 완료 근거 | 실행 2회, 사례 1건. 미승인 재실행이면 실패 |
| 반환 유실 | 시도 있음, 턴 완료·사용량 근거 없음 | 실행 미확인, 사용량 미상, 자동 재호출 0회 |
| 다른 배정 또는 역할 개정 | 서명된 내용과 배정 원장의 식별자 불일치 | 실패, 결과 확정 보류 |

재심은 후보 구현의 검증 결과를 정식 착수의 선행 조건에 포함했다. 새 후보를 만들 권한과 후보를 인수할 권한을 나눠야 이 순환을 해소할 수 있다. 제안은 프로젝트 소유자가 로컬 합성 환경에서 후보를 만드는 범위와 담당을 먼저 결정하고, 후보 SHA가 생긴 뒤 독립 검증기를 통한 인수를 진행하는 것이다. 이 제안은 미승인이다.
