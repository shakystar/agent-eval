# M4 · 독립 검토 역할의 추론 수준 비교

M3 최종 인수에서 유지하거나 채택한 연구팀 독립 검토 역할(acl-025)을 대상으로 한다. 비용 단위는 제공자가 보고한 입력·출력 토큰이며 캐시 입력은 입력의 부분집합으로 기록한다. 시간은 배정 시작부터 결과 영수증까지 측정한다.

| 통제 항목 | 첫 비교 범위 |
|---|---|
| 기준과 후보 | 기준 gpt-6.2-astra/high, 후보는 같은 모델의 medium. 오케스트레이터가 두 설정을 전달하고 실제 응답에 반영됐음을 확인한다. |
| 동결 | 실험 전에 역할 본문과 모델 식별자, 인프라 커밋, 입력·고정 초안 해시, 기대 판정, 실행 순서, 마감, 블라인드 채점 기준을 기록한다. 개발팀에는 미공개 정답을 제공하지 않는다. |
| 최소 사례 | 진행과 보류가 정답인 사례 각 1개를 양쪽에 1회씩 배정한다. 총 4배정이며 순서는 사례마다 뒤집는다. 동일 슬롯 재호출은 0회다. |
| 관측 | 배정별 적격성, 과보류·오통과, 토큰 세 종류와 경과 시간, 기술 실패·미상·추가 호출을 기록한다. 소수 표본의 캐시 차이와 실행 순서를 함께 보고한다. |
| 해석 | 오통과 또는 보류 누락이 있으면 원본을 검토한다. 호출 수나 모델 설정을 확인할 수 없으면 비교를 보류한다. 2쌍만으로 운영 명부의 모델 설정을 변경하지 않는다. |
| 인계 | 독립 인수팀이 품질·비용 대응표와 유지·확대 검토·판정불가 중 권고 하나를 제출한다. 확대 시 추가 사례의 판정 목적과 예상 사용량을 제시한다. |

실행 선행 조건은 M3 병합 커밋과 역할 계약 최종 판정이다. CAL01에서 관측한 2회 합산 입력·출력 15,502토큰을 단순 환산하면 4회는 약 31,004토큰이다. 이는 기존 한 사례의 참고치이며 모델별 비용 보장치가 아니다.
